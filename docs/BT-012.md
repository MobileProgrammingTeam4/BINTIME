### 칸 번호는 화면 내부 값

칸 번호(행/슬롯 인덱스)는 **화면 그리기용 내부 값이며 계약이 아니다.** 저장·전달·서버 계약에는 분(minute)만 사용한다. 현재 코드에는 칸 번호 기준이 두 가지 있고, 이번 PR에서 코드는 바꾸지 않았다.

| 기준 | 칸 0 | 계산식 | 범위 |
|---|---|---|---|
| **BT-012 행 번호** (`TimeSlot.getStartSlotIndex`, `TimeUtils.minutesToSlotIndex`) | 09:00 | `row = (minute - 540) / 30` | 0~17. `TimeUtils.minutesToSlotIndex`는 0~17로 clamp하고, `TimeSlot.getStartSlotIndex`는 09:00 이전만 0으로 clamp한다(18:00 이후는 18 이상). 09:00~18:00 밖은 행으로 표현되지 않음 |
| **develop 칸 번호** (`TimetableDraft`, `TimetableWeekView`) | 00:00 | `slot = minute / 30` | 0~47. 기본 표시 18~36(09:00~18:00), 범위 밖 수업이 있으면 시간축이 확장됨 |

```text
develop 칸 번호 = BT-012 행 번호 + 18        (09:00~18:00 범위, 행 0~17에서만 성립)
minute         = develop 칸 번호 × 30
               = 540 + BT-012 행 번호 × 30
```

## ② Class / FreeSlot 모델

수업(Class)은 `Course` + `TimeSlot`, 공강(FreeSlot)은 `Timetable.freeSlots`의 `TimeSlot`으로 표현한다. 공강 전용 클래스는 따로 두지 않는다.

| 클래스 | 필드 | 규칙 |
|---|---|---|
| `TimeSlot` (Parcelable) | `dayOfWeek`, `startMinute`, `endMinute` | equals는 세 값 비교. `getDurationMinutes`, `overlapMinutes`, `overlaps` 제공 |
| `Course` (Parcelable) | `courseId`, `name`, `professor`, `classroom`, `colorCode`, `timeSlots` | `courseId`는 생성 시 UUID, **equals/hashCode는 courseId만 비교**. 한 수업이 여러 슬롯(예: 월·수)을 가질 수 있다. `createSingle()`은 요일·시간 파싱 실패 또는 종료 <= 시작이면 슬롯 없이 반환한다 |
| `Timetable` (Parcelable) | `timetableId`, `userId`, `semester`, `revision`, `courses`, `freeSlots` | `addOrUpdateCourse`/`removeCourse`는 courseId 기준이며 변경 때마다 `revision` +1. 생성 시 revision 1 |

### develop `timetable.Course`와의 변환

develop 시간표 화면은 `timetable.Course`(Serializable, `day` 문자열, `"HH:mm"` 시간)를 계속 사용한다. 이번 PR은 그 클래스를 수정하지 않고 `data.model.Course`에 변환 메서드만 추가했다.

| 메서드 | 동작 |
|---|---|
| `Course.fromLegacy(legacy)` | `legacy == null`이면 **null 반환**. 레거시에 ID가 없으므로 **호출마다 새 courseId**를 만든다. 요일·시간이 잘못됐거나 종료 <= 시작이면 슬롯 없이 반환한다. professor·colorCode는 null이다 |
| `course.toLegacy()` | **슬롯이 여러 개면 첫 슬롯만 변환**하고 나머지는 버린다. **슬롯이 없으면 day·startTime·endTime이 null인 객체**를 반환한다(반환값 자체는 null이 아니며, 기본 시간을 지어내지 않는다). 레거시는 null 요일을 "월", null 시간을 0분으로 해석하므로 호출측이 슬롯 유무를 먼저 확인해야 한다. courseId·professor·colorCode는 전달되지 않는다 |

develop의 공강은 `TimetableDraft.freeSlots`(`long[5]`, 월~금 요일별 비트마스크, 비트 i = 자정 기준 칸 i)로 표현된다. `TimeSlot`으로 바꿀 때는 연속 비트 `[i, j)`를 `TimeSlot(day + 1, i × 30, j × 30)`으로 묶는다. develop 공강 표현은 토·일을 지원하지 않는다. 이 변환 코드는 이번 PR에 포함하지 않았다.
