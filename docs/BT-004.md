## PR #74 리뷰 반영

- **프로필 데이터 공유**: `ProfileSetupActivity`와 `MyPageFragment`가 각자 `new MockProfileRepository()`를 만들던 구조를 `MockProfileRepository.shared()` 하나로 통일했다 (`MockChatRepository.shared()`와 같은 방식). 수정 화면에서 저장하면 마이페이지 `onResume()`에서 바로 반영된다.
  - `getProfile()`은 복사본을 돌려주고 `saveProfile()`도 복사본을 저장한다. 수정 화면에서 값을 바꾼 뒤 "수정 취소"로 나가면 저장값이 바뀌지 않는다.
  - 화면 회전 시 저장소를 다시 읽지 않고 작성 중인 입력값·선택 태그를 그대로 복원한다.
- **필수 입력값 검증**: `ProfileValidator`를 추가했다. 닉네임·학과가 비어 있거나 공백뿐이면 입력칸 아래에 안내 문구를 띄우고 저장·화면 이동을 하지 않는다. 같은 검증을 `MockProfileRepository.saveProfile()`에서도 수행한다.
- **프로필 최초 생성**: 생성 모드는 시연용 "김지민" 값을 채우지 않은 빈 폼으로 시작하고, 인증된 UID와 이메일만 연결한다. 저장 후 `MainActivity`를 새 태스크로 시작해 뒤로가기로 온보딩·인증 화면에 돌아가지 않는다.
- **로그아웃**: `MockAuthRepository.shared().signOut()` 후 온보딩으로 이동한다.
- Mock 데이터는 메모리에만 있으므로 앱 프로세스가 종료되면 기본값으로 돌아간다. 앱 재시작·다른 기기 간 유지는 BT-015(Firestore) 범위다.

## Galaxy S25 시스템 바 겹침·Figma 정렬

- **원인**: targetSdk 36 앱은 Android 15+ 기기에서 상태바·내비게이션바 뒤까지 화면을 그린다. 온보딩·인증·프로필 설정 화면에는 그 여백 처리가 없어 앱바가 시계와, 하단 버튼이 내비게이션바와 겹쳤다.
- **수정**: 다른 화면(FilterActivity, ReportActivity 등)과 같이 루트에 `android:fitsSystemWindows="true"`를 지정했다. 마이 탭은 MainActivity가 처리한다.
- **공통 컴포넌트 재사용**: 수정 취소·로그아웃·회원 탈퇴 확인은 `ConfirmDialog`, 활동 태그는 `ChipViews.interest`, 하단 버튼은 `Widget.BinTime.PillPrimary`, 제목·본문은 `TextAppearance.BinTime.*`를 쓴다. 회원 탈퇴는 실제 삭제가 없으므로 "목업" 안내만 띄운다.
- **학과 선택 (PR #76 리뷰)**: 학과 칸을 직접 입력에서 선택 방식으로 바꿨다. 누르면 학과 검색 화면(`DepartmentSearchActivity`, Figma 116:2685)으로 이동하고, 학과명·소속으로 검색한 뒤 '선택'을 누르면 프로필 화면에 반영된다. 뒤로가기는 선택 취소이며 기존 학과를 유지한다. 학과 목록은 시연용 `MockDepartmentRepository`이며 실제 목록 연동은 BT-015 범위다. 결과가 없으면 공통 `StateView` 빈 상태를 띄운다.
