# BT-005 · BT-006 시간표 표시 규칙

- 가입 순서는 학교 이메일 링크 인증 → 시간표 입력 방식 선택 → 수업 검수 → 공강 선택 → 프로필 설정이다.
- 입력 화면의 요일은 `월요일`부터 `금요일`까지 표시한다. 주간 시간표의 열과 수업 요약에는 `월`부터 `금`까지 한 글자 약칭을 사용한다.
- 입력 시 오전·오후를 선택하고 수업 목록에는 24시간제 `HH:mm`으로 표시한다. 수업 요약은 `월 10:00 ~ 11:30 · 공학관 302호` 형식이다.
- 주간 시간표는 기본 09:00~18:00을 표시한다. 범위 밖의 수업을 추가하면 해당 시간까지 시간축을 확장한다. 종료 시각은 수업에 포함하지 않으므로 앞 수업이 끝나는 시각에 다음 수업을 시작할 수 있다.
- 빈 칸은 30분 단위로 선택하거나 해제할 수 있다. 연속으로 선택한 칸은 연한 분홍색으로 이어서 표시하고 첫 칸에 `공강`을 붙인다. 수업과 겹치는 칸은 선택할 수 없다. 공강 선택 단위와 매칭의 최소 겹침 시간은 별개다.
- 시연에서는 다중 이미지의 미리보기를 보여주고 고정 인식 예시로 수업 검수를 시작한다. 확인한 수업과 공강은 인증된 목업 계정의 앱 세션에서 공유한다. 실제 저장·공강 계산은 BT-015/016, 이미지 업로드·Gemini 인식은 BT-025/026에서 연동한다.
