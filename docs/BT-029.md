# BT-029 Gemini 자기소개 생성 및 선호 태그 추천 (Issue #29)

담당: B (인증/프로필) · 선행: BT-014(#14), BT-024(#24)

## 동작

1. 프로필 설정·수정 화면에서 **AI로 작성하기**를 누른다.
2. 학과가 없으면 서버를 부르지 않고 "학과를 먼저 선택해 주세요"를 안내한다.
3. 내 시간표에서 **수업 이름만** 한 번 읽는다(시간·교수·강의실은 보내지 않음). 시간표가 없거나 못 읽으면 과목 없이 진행한다.
4. `generateProfile` Callable(asia-northeast3)을 부른다. 버튼은 끝날 때까지 "작성 중…"으로 막는다(중복 요청 방지).
5. 성공하면
   - 초안을 자기소개 입력칸에 넣는다. **저장 전이며 자유롭게 고칠 수 있다.**
   - 안내 카드(Figma 41:10218)에 실제로 보낸 과목 이름을 보여 준다. 예: "시간표의 ‘자료구조’, ‘운영체제’ 수업을 바탕으로 작성했어요". 과목이 없으면 "학과와 선택한 활동을 바탕으로 작성했어요".
   - 추천 태그를 **AI 추천** 줄에 보여 준다. 자동으로 선택하지 않고, 사용자가 고른 태그만 저장된다.
6. 실패하면 사유별 안내를 띄우고 직접 입력은 그대로 할 수 있다(아래 표).

요청은 `ProfileAiViewModel`이 맡아 화면이 회전해도 이어지고, 결과는 한 번만 처리한다. 초안·안내 카드·추천 태그는 회전 후에도 유지된다.

### AI 추천 줄

- 보여 주는 태그 = 이번 AI 추천 + 이미 고른 태그 중 기본 목록에 없는 것(예전에 AI 추천으로 고른 태그).
- 기본 목록에 있는 추천 태그는 아래 **기본 활동 태그** 줄에만 보인다(같은 태그를 두 번 보이지 않음).
- 보여 줄 태그가 없으면 줄을 숨긴다(AI를 쓰기 전에 가짜 추천을 보여 주지 않음).
- 이전에는 기본 목록에 없는 저장 태그가 수정 화면에 보이지 않아 선택을 풀 수 없었는데, 이 줄에 보이도록 고쳤다.

## 보내는 값 (개인정보 최소)

| 필드 | 값 | 제한(앱에서 맞춤) |
|---|---|---|
| `department` | 선택한 학과 | 40자 |
| `grade` | "3학년" → 3 | 1~6 |
| `preferredActivities` | 지금 고른 태그(`#` 없이) | 10개, 각 20자 |
| `courseNames` | 시간표 수업 이름 | 20개, 각 60자, 중복 제거 |
| `draftBio` | 작성 중인 소개(비어 있으면 안 보냄) | 150자 |

이름·이메일·UID·닉네임·성별·사진은 보내지 않는다. 서버는 토큰으로 사용자를 확인한다.

## 서버 (`functions/src/ai/tasks/generateProfile.ts`)

- live 프롬프트(`buildRequest`): 입력은 JSON 데이터로만 다루고 값 안의 지시문은 따르지 않는다. 해요체 1~2문장 150자 이내, 입력에 없는 사실(이름·나이·MBTI 등)·연락처·연애/소개팅 표현 금지, 친구·스터디 메이트 톤.
- 태그: `#`·앞 공백 제거, 중복(대소문자 무시) 제거, 최대 5개. 모델이 `#`을 붙여도 실패시키지 않고 정리한다. Mock 응답도 `#` 없이 바꿨다(BT-012 #3).
- 소개에 이메일·전화번호(숫자 9자리 이상)·링크가 있으면 `AI_INVALID_OUTPUT`으로 1회 다시 요청하고, 계속 있으면 실패로 돌려준다.
- 제한 시간 10초, 사용자별 하루 20회(BT-024 공통 처리).

## 오류 안내

| 사유 | 안내 |
|---|---|
| `QUOTA_EXCEEDED` | 오늘 AI 작성 횟수를 모두 썼어요. 직접 입력해 주세요 |
| `AI_RATE_LIMITED` | AI 요청이 많아요. 잠시 후 다시 시도해 주세요 |
| `AI_TIMEOUT`, `AI_INVALID_OUTPUT` | AI가 응답하지 못했어요. 다시 시도해 주세요 |
| `AI_BLOCKED` | AI가 작성할 수 없는 내용이에요. 직접 입력해 주세요 |
| `AI_UNAVAILABLE`, `AI_NOT_IMPLEMENTED` | 지금은 AI 작성을 쓸 수 없어요. 직접 입력해 주세요 |
| `PERMISSION_DENIED` | 학교 이메일로 인증한 계정만 AI 작성을 쓸 수 있어요 |
| `UNAUTHENTICATED` | 로그인이 필요해요. 다시 로그인해 주세요 |
| 네트워크 | 네트워크 연결을 확인해 주세요. |
| 그 밖 | AI 작성에 실패했어요. 직접 입력해 주세요 |

## Mock

`MockProfileRepository.generateAiProfile`은 Gemini 없이 입력으로 정해진 초안(학과·학년·첫 과목)과 추천 태그 3개(이미 고른 활동 제외)를 돌려준다. 화면 흐름 확인용이다.

## 배포

앱은 이미 배포된 `generateProfile` 함수를 그대로 부른다. **live 프롬프트는 이 PR 병합 후 `generateProfile` 함수를 다시 배포해야 동작한다.** 그 전에는 서버가 `AI_NOT_IMPLEMENTED`를 돌려주고 앱은 "지금은 AI 작성을 쓸 수 없어요"를 안내한다.

```
firebase deploy --only functions:generateProfile --project bintime-mobile
```
